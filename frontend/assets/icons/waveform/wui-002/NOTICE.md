# WUI-002 artwork provenance

These eight SVGs were extracted from the owner-supplied
approved HTML mockup (the supplied second copy is identical).
The exact source filename remains recorded in `provenance.json`.
The owner explicitly requested reuse of the exact SVGs and retention of existing
icons for gaps. `provenance.json` records the source SHA-256, original icon keys,
control mappings and geometry hashes.

The mockup defines inline SVG strings, not external SVG assets or a generated
icon library. Original geometry, 24-unit viewBox, 1.8 stroke, round caps and
round joins are retained. Only the SVG wrapper makes the mockup CSS attributes
explicit for standalone files; the application masks them using currentColor.

No upstream license declaration, vendor identity or attribution requirement was
identified in the supplied HTML. Reuse is based on the owner's supplied design
and explicit instruction. This notice does not assert a third-party license or
ownership beyond that evidence. No new external dependency is included.
